║             PLANNING PATTERN                      ║
╚══════════════════════════════════════════════════╝

         [GOAL]
           ↓
    ┌──────────────┐
    │  Decompose   │
    │  Milestones  │
    └──────────────┘
           ↓
    ┌──────────────┐
    │ Dependency   │
    │    Graph     │
    └──────────────┘
         A → B
         ↓   ↓
         C → D → E
           ↓
    ┌──────────────┐
    │  Allocate    │←── Constraints
    │  Resources   │    (time/budget)
    └──────────────┘
           ↓
    [Execute Steps]
         ↓ ↑
    ◆ Checkpoint ◆ ← Monitor & Replan
         ↓
    [GOAL MET]

KEY CONCEPTS:
• Milestone mapping
• Dependency tracking
• Resource allocation
• Adaptive replanning

SUMMARY:
The Planning pattern decomposes a goal into
milestones, builds a dependency graph, and
allocates resources under constraints like time
and budget. Execution proceeds step by step with
checkpoints that monitor progress. When a step
is blocked or new information arises, the agent
replans dynamically rather than failing. This
pattern trades upfront planning overhead for
strategic, adaptive execution that handles
complex, long-running, multi-step projects.
